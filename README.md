# IPL Analysis Dashboard (2008–2025)

An interactive Power BI dashboard developed to analyze Indian Premier League (IPL) data from 2008 to 2025 using Power BI, DAX, and Power Query. The dashboard provides insights into team performance, player statistics, match results, and tournament trends through interactive visualizations and key performance indicators (KPIs).

## Project Overview

This project provides a comprehensive analysis of IPL seasons from 2008 to 2025. It helps users explore team performance, player achievements, match statistics, and season-wise trends through interactive reports and visualizations. The dashboard demonstrates data cleaning, transformation, modeling, and business intelligence techniques using Power BI.

## Features

- Season-wise IPL Analysis (2008–2025)
- Tournament Winners and Runners-up
- Orange Cap Analysis
- Purple Cap Analysis
- Team Performance Analysis
- Player Performance Analysis
- Most Sixes and Fours
- Toss Decision Analysis
- Match Result Analysis
- Venue-wise Performance
- Interactive Filters and Slicers
- Dynamic KPI Cards

## Technologies Used

- Power BI Desktop
